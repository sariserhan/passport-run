# Additional destination artwork

Generated using the built-in image-generation tool, copied into the repository and visually inspected. Each atlas is 1024×1536 with four 512×768 portrait scenes. Runtime uses clipped AtlasTextures over the same interactive stone path. These are stylized original compositions, not film stills or geographically literal maps.

Assets: `assets/landmarks-0.png` through `landmarks-3.png`, `assets/fantasy-0.png` and `fantasy-1.png`, `assets/cinema-0.png` and `cinema-1.png`. Scene order and stamp metadata are in the matching geography JSON files. No actors, logos or copied screenshots are included.
